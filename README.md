# 🔐 Keyspace

**Stronger passwords. A safer you.**

Keyspace is a password security toolkit that helps you create strong passwords, generate random PINs, check existing passwords for weaknesses, and understand what makes them secure.

## 🚀 Try Keyspace

[**Visit Keyspace →**](https://mohamed-mt.github.io/Keyspace/)

## What can you do with Keyspace?

### 🔑 Generate Strong Passwords

Create passwords that fit your needs. Choose the length, select which character types to include, and generate up to five options at once.

You can reveal or hide each password, copy it, check its estimated strength, or generate a replacement.

### 📟 Generate Random PINs

Generate random numeric PINs with lengths ranging from **3 to 50 digits**. Choose the length you need and create a PIN for your use case.

### 🛡️ Check Your Passwords

Check for common weaknesses, including repeated characters, simple sequences, keyboard patterns, and passwords that are easy to guess.

Keyspace explains what could make a password weaker and gives you two options: strengthen your existing password or generate a completely new one.

### 📘 Learn About Password Security

Learn how password length, character variety, and randomness affect security. Understand password entropy, why predictable passwords are risky, and how password managers and two-factor authentication can help protect your accounts.

## How does Keyspace create strong passwords and PINs?

Keyspace uses your device's **cryptographically secure random number generator** to create passwords and PINs. Random values help make generated credentials difficult to predict.

For passwords, you can choose which character types to include, exclude confusing characters, and adjust the length. For PINs, you can choose any length from 3 to 50 digits.

### 🔒 What makes the randomness secure?

Keyspace uses JavaScript's **`crypto.getRandomValues()`** instead of `Math.random()` to generate passwords and PINs.

Unlike `Math.random()`, which is not designed for security-sensitive tasks, `crypto.getRandomValues()` provides cryptographically strong random values suitable for generating credentials.

Keyspace also uses **rejection sampling**, a technique that helps prevent bias when converting random values into password characters. This helps ensure that some characters are not unintentionally favored by the selection process.

Together, these techniques help create passwords and PINs that are harder to predict.

### How does it help avoid duplicate passwords?

Keyspace includes a session-based duplicate check to help prevent it from generating the same password more than once during your current session. If a duplicate is detected, it can generate another option.

This helps keep generated passwords distinct within that session, but it cannot guarantee that a password will never match one generated by someone else or in another session.

## A note on password safety

Password strength estimates are guides, not guarantees. Checking a password cannot prove that it has never been exposed in a data breach or that it is safe to reuse.

A longer PIN has more possible combinations than a shorter one, but its security also depends on how it is used and protected. For better protection, use unique passwords for your accounts and consider a reputable password manager.
