# 🔐 Keyspace

**Stronger passwords. A safer you.**

Keyspace is a password security toolkit that helps you create strong passwords, check existing ones for weaknesses, and understand what makes a password secure.

## 🚀 Try Keyspace

**[Visit Keyspace →](https://mohamed-mt.github.io/Keyspace/)**

## What can you do with Keyspace?

### 🔑 Generate Strong Passwords

Create passwords that fit your needs. Choose the length, select which character types to include, and generate up to five options at once.

You can reveal or hide each password, copy it, check its estimated strength, or generate a replacement.

### 🛡️ Check Your Passwords

Check for common weaknesses, including repeated characters, simple sequences, keyboard patterns, and passwords that are easy to guess.

Keyspace explains what could make a password weaker and gives you two options: strengthen your existing password or generate a completely new one.

### 📘 Learn About Password Security

Learn how password length, character variety, and randomness affect security. Understand password entropy, why predictable passwords are risky, and how password managers and two-factor authentication can help protect your accounts.

## How does Keyspace create strong passwords?

Keyspace uses your device's **cryptographically secure random number generator** to create passwords. Instead of choosing characters in a predictable order, it uses random values to select characters from the types you allow, such as uppercase letters, lowercase letters, numbers, and symbols.

It also uses a fair selection method to help ensure that characters are not favored simply because of how the random values are mapped.

You can customize the character choices, exclude confusing characters, and set the password length to suit your needs.

### How does it help avoid duplicate passwords?

Keyspace includes a session-based duplicate check to help prevent it from giving you the same generated password more than once during your current session. If a duplicate is detected, it can generate another option.

This helps keep the passwords generated in that session distinct, although it cannot guarantee that a password will never match one generated by someone else or in another session.

## A note on password safety

Password strength estimates are guides, not guarantees. Checking a password cannot prove that it has never been exposed in a data breach or that it is safe to reuse.

For better protection, use a unique password for every account and consider a reputable password manager.
